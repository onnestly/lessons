# Telegram-бот для составления конспектов лекций

Бот принимает аудиозапись лекции, выбранный режим конспекта и возвращает PDF. Распознавание речи (Whisper) и обработка текста (Ollama) выполняются локально.

## Режимы

| Режим | Результат |
|---|---|
| Подробный | Вся полезная информация лекции |
| Обычный | Основные мысли, определения, не более двух примеров |
| Краткий | Ключевые тезисы и пункты для запоминания |
| По теме | Только информация по указанной теме |

## Требования

- Windows 10/11, Python 3.11+
- FFmpeg
- Ollama с моделью `qwen2.5:7b`
- Токен бота от @BotFather

## Установка

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
ollama pull qwen2.5:7b
copy .env.example .env
```

В `.env` укажите `TELEGRAM_BOT_TOKEN`.

## Запуск

```powershell
python main.py --check
python main.py
```

## Структура

| Файл | Назначение |
|---|---|
| `1_bot.py` | Интерфейс Telegram |
| `2_audio.py` | Подготовка звука (FFmpeg) |
| `3_transcription.py` | Распознавание речи |
| `4_cleaning.py` | Очистка текста, клиент Ollama |
| `5_conspect.py` | Построение конспекта |
| `6_pdf.py` | Создание PDF |
| `config.py` | Настройки из `.env` |
| `main.py` | Проверка компонентов и запуск |

## Ограничения

Файл до 20 МБ (ограничение Telegram), запись до 120 минут. Обработка одной записи за раз.
